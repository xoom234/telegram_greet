# Склад табака: Telegram-бот и Mini App

Учёт прихода, расхода и остатков табака. Данные хранятся в Google Таблице
(листы «Склад», «Накладные», «Бренды», «Фасовки»), работа с ними — через
бота [@sklad_tabak_bot](https://t.me/sklad_tabak_bot) и Mini App внутри Telegram.

Рабочий адрес: <https://telegram-greet-omega.vercel.app/>

## Как пользоваться

- **Приложение** — кнопка «Склад» слева от поля ввода или «Открыть склад» после `/start`.
  Вкладки: «Остатки», «Запись» (приход/расход), «Журнал» за день.
  После записи бот присылает подтверждение в чат.
- **Команды бота** (полный список — `/help`):
  - `/приход 04.10.2026 Сарма классик Буратино 200 г 10 Федя`
  - `/расход 04.10.2026 Сарма классик Буратино 200 г 5 Федя`
  - `/остатки`, `/остатки Сарма классик`
  - `/инфо 04.10.2026` — кто что внёс за день

## Устройство

```
Telegram ──webhook──▶ api/webhook.py ─┐
Mini App (webapp/) ──▶ api/v1.py ─────┼─▶ bot/repository.py ──▶ Google Таблица
UptimeRobot ─────────▶ /api/v1/status ┘
```

Всё работает на Vercel (бесплатный тариф Hobby) из этого репозитория.

| Путь | Что это |
|---|---|
| `api/webhook.py` | Vercel-функция: принимает апдейты Telegram, проверяет `WEBHOOK_SECRET` |
| `api/v1.py`, `bot/api.py` | HTTP API для Mini App (Starlette), авторизация по подписи Telegram initData |
| `bot/handlers/` | Команды бота |
| `bot/repository.py` | Единственное место работы с Google Sheets |
| `bot/services.py` | Общая логика бота и API: даты, бренды, фасовки, остатки |
| `bot/alerts.py` | Сообщения владельцу об ошибках в Telegram |
| `bot/health.py` | Глубокая проверка для мониторинга |
| `webapp/` | Mini App: React + Vite + Telegram WebApp SDK |
| `scripts/set_webhook.py` | Установка / проверка / удаление webhook |
| `deploy/` | Файлы для VPS (systemd) — сейчас не используются |

### Запись в таблицу

- Новая строка вставляется одним атомарным `batchUpdate` (insertDimension + pasteData),
  поэтому одновременные записи бота и приложения не затирают друг друга.
  Совпавший номер накладной при одновременной записи перенумеровывается автоматически.
- Mini App отправляет `request_id`; повтор после обрыва связи не создаёт дубль.
- Текст, начинающийся с `=`, `+`, `-`, `@`, пишется как текст, а не формула.
- Расход больше остатка разрешён, но приложение просит подтверждение.

## Обновление

Изменили код → `git push` в `main` → Vercel сам собирает и выкладывает новую версию
примерно за минуту. Коммиты должны быть от автора, привязанного к GitHub
(иначе Vercel блокирует деплой).

Перед отправкой:

```bash
.venv/bin/python -m pytest -q
cd webapp && npm run build
```

## Настройки (секреты)

Секреты хранятся **только** в Vercel → Project `telegram-greet` → Settings →
Environment Variables. В репозитории их нет и быть не должно (`.env` в `.gitignore`).
Шаблон для локального запуска — `.env.example`.

| Переменная | Обязательна | Назначение |
|---|---|---|
| `BOT_TOKEN` | да | Токен бота от BotFather |
| `SHEET_URL` | да | Ссылка на Google Таблицу |
| `GOOGLE_CREDENTIALS_JSON` | да (Vercel) | JSON ключа сервисного аккаунта одной строкой. Локально вместо него `GOOGLE_CREDENTIALS` — путь к файлу |
| `WEBHOOK_SECRET` | да | Секрет, которым Telegram подписывает webhook |
| `ADMIN_CHAT_ID` | нет | Telegram id для сообщений об ошибках (пусто — выключено) |
| `ALLOWED_USER_IDS` | нет | id через запятую; пусто — доступ у всех |
| `DEFAULT_AUTHOR` | нет | Автор по умолчанию (`Федор`) |
| `APP_TIMEZONE` | нет | Часовой пояс для «сегодня» (`Europe/Samara`) |
| `WEBAPP_URL` | нет | Адрес Mini App для кнопки в `/start` |
| `CACHE_TTL_SECONDS` | нет | Кэш брендов и фасовок, с (300) |
| `MOVEMENTS_CACHE_TTL_SECONDS` | нет | Кэш движений, с (10) |

После изменения переменных нужен новый деплой (любой push или Redeploy в Vercel).
Сервисному аккаунту должен быть выдан доступ «Редактор» к таблице.

## Мониторинг и логи

- **Ошибки** в боте, webhook и API приходят владельцу в Telegram (`ADMIN_CHAT_ID`);
  одинаковая ошибка — не чаще раза в 10 минут. Разовые сбои (Google или Telegram
  не ответили, лимит запросов, таймаут) в Telegram не отправляются — только в лог.
- **`/api/v1/status`** — проверяет доступ к таблице и состояние webhook
  (200 — всё в порядке, 503 — с причиной). Разовый сбой перепроверяется через 2 с.
  В Telegram пишет только о серьёзном: нет доступа к таблице, webhook сброшен
  или указывает не туда, в очереди больше 20 сообщений.
- **UptimeRobot** проверяет `/api/v1/status` каждые 5 минут и пишет на почту
  при любом 503 — так заметен и длительный простой Google или Telegram.
- **Логи Vercel** (Project → Logs) хранятся 1 час на бесплатном тарифе.
- `/api/v1/health` — лёгкая проверка «функция жива», без обращения к таблице.

## Локальная разработка

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt -r requirements-dev.txt
cp .env.example .env   # заполнить
.venv/bin/python -m pytest -q
cd webapp && npm ci && npm run dev   # интерфейс, API проксируется на прод
```

Для открытия интерфейса в обычном браузере нужна подписанная initData в
`webapp/.env.local` (`VITE_DEV_INIT_DATA`), она действует 24 часа.

## Если что-то сломалось

- **Бот молчит:** `.venv/bin/python scripts/set_webhook.py --info` — проверить адрес и
  последнюю ошибку webhook. Переустановить:
  `.venv/bin/python scripts/set_webhook.py https://telegram-greet-omega.vercel.app/api/webhook`
- **«Нет доступа к таблице»:** выдать сервисному аккаунту доступ «Редактор».
- **Откат на локальный запуск (polling):** `scripts/set_webhook.py --delete`,
  затем запустить бота на компьютере.
- **Откат версии:** Vercel → Deployments → нужный деплой → Promote to Production.

## Ограничения

- Vercel Hobby по правилам — только некоммерческое использование.
  При блокировке — перейти на Pro, код менять не нужно.
- Доступ открыт всем, кто найдёт бота; каждая запись подписана именем и Telegram id.
